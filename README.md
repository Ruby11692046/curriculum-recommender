# おすすめ履修診断

ZEN大学の学生向けに、これまでの履修科目・難しかった科目の申告と、簡単な4択質問への回答から、次に履修すべき科目を分析・提案するWebアプリです。

## コンセプト

科目の「難易度」や「おすすめ度」をあらかじめサイト側で持つのではなく、 **利用者自身の履修履歴と価値観(質問の回答)** を起点にデータを組み立て、その人向けの推薦を生成します。ZEN大学の公開シラバスAPIから取得した科目データと組み合わせることで、実際に開講されている科目の中から、その人の傾向に合ったものを提示します。

## できること

1. 大学の成績照会画面からコピーした履修履歴を貼り付けるだけで、履修済み科目を自動で読み取り
2. その中から「難しかった科目」を選択(履修データが無い場合はスキップも可能)
3. 5つの傾向軸(実践度・論理思考度・表現度・キャリア志向度・自己探究度)を測る4択質問に回答
4. 履修履歴・難易度傾向・質問の回答を組み合わせて、開講中の科目からおすすめを5件表示
5. 各科目からシラバスページへ直接リンク
6. 診断結果を共有(対応端末では共有シート、非対応環境ではクリップボードコピー)

## 使用技術

- HTML / CSS / JavaScript(ESモジュール)のみ
- データ取得: [ZEN大学 公開シラバスAPI](https://api.syllabus.zen.ac.jp/search)
